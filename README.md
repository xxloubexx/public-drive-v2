# Public Drive

Application Node.js de partage de fichiers public sans authentification.

## Fonctionnalités

- Upload de fichiers (.txt et .pdf) par drag & drop ou sélection
- Organisation en dossiers avec navigation par fil d'Ariane
- Prévisualisation intégrée (PDF viewer, texte formaté)
- Téléchargement et suppression de fichiers
- Interface moderne avec thème sombre

## Installation

```bash
npm install
```

## Lancement

```bash
npm start
```

Ouvrir http://localhost:3000

## Technologies

- Node.js + Express
- Multer (upload)
- HTML/CSS/JS vanilla
